# Aydınox Proses Makine Web Sitesi

Nuxt 4 + Nuxt UI ile geliştirilmiş kurumsal web sitesi iskeleti.

## Kurulum

```bash
npm install
```

## Geliştirme

```bash
npm run dev
```

## Production

```bash
npm run build
npm run preview
```

## Yapı

- `app/constants/` — Site içeriği (ürünler, hizmetler, blog, kurumsal)
- `app/components/` — Header, Footer, sayfa bileşenleri
- `app/pages/` — Rotalar
- `public/logo.jpeg` — Firma logosu
